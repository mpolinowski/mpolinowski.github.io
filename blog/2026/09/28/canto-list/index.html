12. The Cantonese “power particles”​

CantoneseJyutpingTypical function
呀aa3softens / makes a question or statement conversational
啦laa1change of state / urging / emphasis
喎wo3new information / drawing attention
嘅ge3emphasis / explanation / possession
㗎gaa3emphasis / assurance
囉lo1obvious conclusion / “that's how it is”
咩me1surprise / challenging a statement
吖aa1casual sentence ending
啫ze1“only / just”
添tim1addition / “even” / “also”
㗎喇gaa3 laa3emphatic change/assurance

Compare:

你食飯。 “You eat / you eat a meal.”

你食飯呀？ “Are you eating?”

你食飯啦。 “Go eat / Let's eat.”

你食咗飯喇。 “You've eaten already.”

The basic vocabulary barely changes, but the particle dramatically changes the conversational feeling.
