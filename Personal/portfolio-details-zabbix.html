Fleet Observability & Alerting (Zabbix)

Project information

  • Category: SysOps
  • Client: Waletech (INSTAR Germany) Shenzhen, China
  • Project date: 01 March, 2018
  • Project URL: www.zabbix.com

Step two after orchestrating deployments with Hashicorp Nomad: knowing when something is going wrong before the customer notices. I integrated Zabbix Server Monitor across the full server fleet — CPU, memory, disk, and network saturation, plus custom health-check API probes for every customer-facing service. System-critical variables are extracted into per-service dashboards, with email and Slack alerts on threshold breach. The result: the Cloud team now gets paged on degradation, not on a customer support ticket.
