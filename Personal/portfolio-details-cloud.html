Bringing it all together! After half a year of optimization and integrations the AI pipeline - providing Object Detection on a custom YOLO model, License Plate and Face Recognition + a SmolVLM szene observer - is now running stable! No longer memory issues, random crashes, GPU thermal throtteling or waiting times of several minutes for predictions under peak load. The new system is deployed and monitored using Hashicorp Nomad and provided with a Zabbix Dahsboard for the Cloud team.
