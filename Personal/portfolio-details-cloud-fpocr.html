ANPR – Fast-Plate-OCR

Project information

  • Category: MLOps
  • Client: INSTAR Deutschland GmbH (Waletech) Shenzhen, China
  • Project date: 01 Nov, 2025
  • Project URL: INSTAR Cloud

Replaced a legacy custom TensorFlow OCR model with a lightweight LiteRT build of Fast-Plate-OCR. The model sits downstream of the main object-detector (a custom LiteRT YOLO) and receives only the cropped plate region. End-to-end plate detection time dropped to single-digit milliseconds on a CPU server; the additional compute footprint is negligible at fleet scale.
