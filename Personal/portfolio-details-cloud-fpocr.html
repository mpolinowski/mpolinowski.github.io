INSTAR Cloud - License Plate Recognition

Project information

  • Category: MLOps
  • Client: Waletech (INSTAR Germany) Shenzhen, China
  • Project date: 01 Nov, 2025
  • Project URL: INSTAR Cloud

Replacing an old custom Tensorflow OCR model with a lightweight LiteRT version of Fast-Plate-OCR. The model is integrated in the INSTAR Cloud AI pipeline and directly fed the cropped license plate detected by the main object detector - a custom LiteRT YOLO model. This setup reduced the detection time to single digit milliseconds on a CPU server and reduced the overall server footprint to barely noticeable.
