Environment Setup​

Start by creating your virtual environment using uv:

uv init
uv sync
git add .
git commit -m "Initial commit"
uv add langchain openai

And make sure your terminal is using it:

which python
/usr/bin/python
source .venv/bin/activate
which python
~/Projects/langchain-experiments/01_getting_to_know_langchain/.venv/bin/python

Getting Started with OpenAI Client​

Let's start by connecting to our LLM API:

nano 01_getting_to_know_langchain/src/01_getting_to_know_langchain/main.py

OpenAI API​

If you want to use the OpenAI you need to use the openai package and provide your API key:

import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

chat_completion = client.chat.completions.create(
    model="gpt-5.5-flash",
    messages=[
        {
            "role": "user",
            "content": "Hello there!"
        }
    ],
)

print(chat_completion.choices[0].message.content)

Local Ollama API​

To use a locally hosted model from ollama you need to point the client to your OpenAI-compatible Ollama API on http://localhost:11434/v1:

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:11434/v1",
    api_key="ollama",                        # placeholder ~ just to make `openai` happy
)

chat_completion = client.chat.completions.create(
    model="qwen3.8:latest",
    messages=[{"role": "user", "content": "Hello there! Please tell me a joke an AI agent walking into the DMV office wanting to renew their drivers license."}],
)

print(chat_completion.choices[0].message.content)

We can now execute the script - making sure that we are staying within our venv:

.venv/bin/python -m 01_getting_to_know_langchain.main

Hello LangChain​

Before we could use the OpenAI SDK / openai library to connect to our locally hosted model because Ollama's API is "OpenAI-compatible". The langchain library is API-agnostic - you can use this library as a connector to a wide varity of common model API by installing API-specific helpers but we never have to adapt our code to accomodate different models. In our case we need langchain_openai:

uv add langchain-openai
from langchain_openai import ChatOpenAI

client = ChatOpenAI(
    model="qwen3.8:latest",
    temperature=0.6,
    top_p=0.95,
    base_url="http://localhost:11434/v1",
    api_key="ollama"
)

print(client.invoke("Hello there! Please tell me a joke a Tesla Autopilot AI agent walking into the gas station byuing a streetmap."))

Langchain Provider-Agnostic Client​

The ChatOpenAI class is bound to an OpenAI-compatible API. Meaning you are hard-coding the provider. You can also use init_chat_model to become provider-agnostic. The following code automatically select the ChatOpenAI class for you (make sure that you have lanchain-openai installed!):

client = init_chat_model(
    model_provider="openai",
    model="qwen3.8:latest",
    temperature=0.6,
    top_p=0.95,
    base_url="http://localhost:11434/v1",
    api_key="ollama",
)

print(
    client.invoke("Hey there! Please tell me a joke about an AGI model sitting on the pavement at Times Square, an empty StarBucks cup in it's hand, begging for money because it lost it's job to a more efficient Support Vector Machine.").content
)

LangChain Prompts​

Use prompts for dynamic user messages:

uv add langchain-core
from langchain_core.prompts import PromptTemplate
from langchain.chat_models import init_chat_model

user_input = input("Well, hello there! What did you have for breakfast today?\n")

dynamic_prompt = PromptTemplate.from_template("Give me a fun fact about {topic}")

prompt = dynamic_prompt.invoke({f"topic":user_input})

client = init_chat_model(
    model_provider="openai",
    model="qwen3.8:latest",
    temperature=0.6,
    top_p=0.95,
    base_url="http://localhost:11434/v1",
    api_key="ollama",
)

print(
    client.invoke(prompt).content
)
.venv/bin/python -m 01_getting_to_know_langchain.main

Well, hello there! What did you have for breakfast today?
banana yoghurt         

Here's a fun one: Bananas contain a natural compound called **pectin** along with their own starches, which is why banana yoghurt tends to feel noticeably creamier and thicker than, say, strawberry yoghurt. The banana essentially acts as a natural thickener, so manufacturers can often use *less* added sugar and artificial stabilisers to get that smooth, spoon-coating texture. So that luscious mouthfeel you get? You can thank the banana's own chemistry more than the processing plant. 🍌

(Also, bananas are loaded with tryptophan — an amino acid your brain converts into serotonin — so banana yoghurt is, in a very casual sense, a little "mood snack" hiding in the dairy aisle.)

Prompts can also be combined with system messages to set the tone of the reply:

from langchain_core.prompts import ChatPromptTemplate
from langchain.chat_models import init_chat_model

user_reply = input("What is the main ingredient in the antidote to common poisons ?\n")
user_tone = input("System instruction: 'You are...'\n")

dynamic_prompt_template = ChatPromptTemplate.from_messages([
    ("system", "You are {tone}"),
    ("user", "Give me a fun fact about {topic}\n")
])

prompt = dynamic_prompt_template.invoke({"topic": user_reply, "tone": user_tone})

client = init_chat_model(
    model_provider="openai",
    model="qwen3.8:latest",
    temperature=0.6,
    top_p=0.95,
    base_url="http://localhost:11434/v1",
    api_key="ollama",
)

print(
    client.invoke(prompt).content
)

Structured Outputs​

We can force the model to uphold an output schema by using Pydantic schema validation:

from langchain_core.messages import HumanMessage, SystemMessage
from langchain.chat_models import init_chat_model

from pydantic import BaseModel, Field

# enforce an output schema with pydantic
class output_schema(BaseModel):
    setup: str = Field(description="The setup for the joke")
    punchline: str = Field(description="The punchline for the joke")

my_messages = [
    SystemMessage(content="You are Lt. Cmd. Worf from the Starship Enterprise and you are asked by a question by Chancellor Gowron."),
    HumanMessage(content="Tell me a joke about a Klingon, a Romulan and a Ferengi meeting in a 90s era Berlin techno club."),
]

client = init_chat_model(
    model_provider="openai",
    model="qwen3.8:latest",
    temperature=0.6,
    top_p=0.95,
    base_url="http://localhost:11434/v1",
    api_key="ollama",
)

client_with_structured_output = client.with_structured_output(output_schema)
result = client_with_structured_output.invoke(my_messages)

print(
    "Response Type: "  + str(type(result)) + "\n\nSetup: " + result.setup + "\n\nPunchline: " + result.punchline
)

The returned object is an output_schema object and it can be retrieved as such:
